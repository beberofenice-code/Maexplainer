# Shared audio

Files here are referenced from a project's `storyboard.json` → `audio` as `_shared/audio/<file>`:

- `bgm.mp3` — subtle background music bed
- `sfx/whoosh.mp3` — camera zoom transition whoosh
- `sfx/pop.mp3` — label / counter pop sound

Any file that doesn't exist is skipped, so renders work without them. Narration is per project
(`projects/<slug>/voice.mp3`, generated by `npm run voice -- <slug>`).
